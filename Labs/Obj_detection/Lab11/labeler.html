Pedestrian box labeler

Choose one image, then draw one tight box around each visible pedestrian. Overlapping people need separate boxes. Save the downloaded label file next to the image, with the same base name.

Choose an image to begin.

YOLO label format

Every line in the downloaded file has the form 0 x_center y_center width height. The values are normalized by the image width and height. Class 0 is pedestrian.
