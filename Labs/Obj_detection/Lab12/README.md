# Lab 12 - Train and Evaluate a Pedestrian Detector

Run `lab12_train_evaluate.ipynb` from top to bottom with a GPU runtime.

Keep all files in this folder together. In Google Colab, upload or clone the
complete `Lab12` folder before opening the notebook, so
`detection_dataset.py` remains beside it. Select a T4 GPU runtime.

In VS Code, install the packages with `python -m pip install -r
requirements.txt`, then restart or select that same Python environment as the
notebook kernel.

The first run needs an internet connection to download the Penn-Fudan dataset
and the pretrained YOLO weights.
