# Lab 03: k-NN Classification

First copy your completed Lab 02 distance-function implementations into this
lab's `knn.py`. Then open `knn.ipynb` and complete label prediction and the
`KnnClassifier` class.

Learning goals:

- find nearest neighbors and implement majority voting;
- handle ties deterministically;
- understand the effect of `k` on decision boundaries;
- compare `k=1` and `k=5` on a CIFAR-10 subset.

Cross-validation and selection of the best `k` are reserved for homework.
